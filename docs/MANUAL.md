# Manual de Uso — FireCheck Pro

## Acesso ao Sistema
1. Acesse **https://bcimrea.base44.app**
2. Informe sua **Matrícula** (ex: CILOIMREA) e **Senha**
3. Clique em **"Acessar Painel"**

## Perfis de Acesso (RBAC)
- **CILO** (Administrador): Gestão completa, todos os módulos
- **DIREX** (Gerencial): Dashboard, consultas, relatórios
- **BOMBEIRO** (Operacional): Vistorias técnicas, checklists, RNC
- **BRIGADISTA** (RNC Apenas): Registro de Não Conformidades

## Módulos Disponíveis
- Vistorias Técnicas: IT-22, IT-19, IT-21, PCF, Saídas, IT-16
- Registros Especiais: RNC, APH, Kit Trauma
- Gestão: DEA, Equipamentos, Relatórios, Gerenciador

## Fluxo de Vistoria
1. Selecione o módulo no menu lateral
2. Selecione o equipamento (quando aplicável)
3. Preencha o checklist (SIM/NÃO/NC)
4. Adicione justificativas para itens NÃO/NC
5. Clique em **"Confirmar e Enviar"**
6. O relatório é emitido e arquivado no banco central
7. Use **"Imprimir"** para gerar o PDF

## Sincronização
- Checklists são salvos automaticamente na nuvem
- Sincronização em tempo real entre usuários
- Status "Salvo na nuvem" aparece no topo da página
